# 🚀 Git & GitHub Learning Guide
# Hello everybody
Welcome! This repository is designed for beginners who want to learn **Git** and **GitHub** from scratch. By following this guide, you'll understand the basics of version control, work with repositories, and collaborate on projects using GitHub.

---

## 📚 What You'll Learn

- What is Git?
- What is GitHub?
- Installing Git
- Basic Git commands
- Creating a local repository
- Connecting to GitHub
- Pushing and pulling code
- Branching and merging
- Working with Pull Requests
- Best practices for Git

---

## 🛠 Prerequisites

Before getting started, make sure you have:

- A computer with Windows, macOS, or Linux
- Git installed
- A GitHub account
- A code editor (recommended: VS Code)

---

## 📂 Learning Path

### 1. Introduction to Git
Learn what Git is, why developers use version control, and how Git tracks changes in your code.

### 2. Setting Up Git
Install Git and configure your username and email.

### 3. Creating Your First Repository
Initialize a Git repository and understand the purpose of the `.git` folder.

### 4. Tracking Changes
Learn how to:
- Check file status
- Stage changes
- Create commits
- View commit history

### 5. Working with GitHub
Create a GitHub repository, connect it to your local project, and push your code online.

### 6. Collaboration
Understand branches, merge changes, resolve conflicts, and create Pull Requests.

---

## 📖 Common Git Commands

| Command | Description |
|---------|-------------|
| `git init` | Create a new Git repository |
| `git status` | Check repository status |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Save changes |
| `git log` | View commit history |
| `git branch` | List branches |
| `git checkout branch-name` | Switch branches |
| `git merge branch-name` | Merge a branch |
| `git clone <url>` | Copy a repository |
| `git pull` | Download latest changes |
| `git push` | Upload changes to GitHub |

---

## 🎯 Practice Exercises

- Create your first repository.
- Add a new file and commit it.
- Push the repository to GitHub.
- Create a new branch.
- Make changes and merge them back.
- Open your first Pull Request.

---

## 💡 Tips for Beginners

- Commit your changes frequently.
- Write meaningful commit messages.
- Pull the latest changes before pushing.
- Practice using branches instead of working directly on the main branch.
- Don't worry about making mistakes—Git makes it easy to track and recover changes.
